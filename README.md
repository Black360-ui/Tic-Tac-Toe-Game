# 🎮 Tic-Tac-Toe Game

A responsive two-player Tic-Tac-Toe game built with React and JavaScript.

Players take turns placing **X** and **O** on a 3×3 game board. The game automatically detects winners, draws, and displays the next player's turn.

## 🎯 How to Play

1. Player **X** starts the game.
2. Click any empty square to place your symbol.
3. Players take turns between **X** and **O**.
4. The first player to get three symbols in a row wins.
5. If all nine squares are filled without a winner, the game ends in a draw.
6. Click **Restart Game** to start a new match.

## 💻 Run Locally

Clone the repository:

```bash
git clone https://github.com/Black360-ui/Tic-Tac-Toe-Game.git
```

Navigate into the project:

```bash
cd Tic-Tac-Toe-Game
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.
